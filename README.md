## 🚀 How to Run Locally

1. Open `index.html` directly in your favorite browser:
   ```powershell
   Start-Process "index.html"
   ```
2. Or serve it locally with Python:
   ```bash
   python -m http.server 3000
   ```
   Open `http://localhost:3000` in your web browser.
