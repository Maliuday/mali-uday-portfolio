01

Public Web Tier

Internet Gateway routes traffic to dual-AZ Application Load Balancers and NGINX instances. NAT Gateway allows instances in private subnets to pull updates without public exposure.

02

Private Application Tier

Application workloads run inside private subnets controlled by an Auto Scaling Group, dynamically adapting to traffic demands and supervised by CloudWatch alarms.

03

Isolated Database Tier

Multi-AZ Amazon RDS deployment provides synchronous standby replication and automated failover with strict zero-public-access security groups.
